# @idempotencykit/nestjs-sqlite

Explicit transactional HTTP idempotency for NestJS Express and local-file SQLite.

**Preview, Node.js 24+ (ES modules). Not yet published.**

Start with the [integration guide](https://github.com/Ahmad09ha/IdempotencyKit/blob/main/docs/GETTING_STARTED.md) and read the [guarantees](https://github.com/Ahmad09ha/IdempotencyKit/blob/main/spec/GUARANTEES.md) before choosing a mode.
